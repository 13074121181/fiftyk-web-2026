# 五十K Web · Final

这是当前可玩的正式 Web 版工程，包含：

- 3 副标准牌，去 1 大王 + 1 小王，共 160 张；4 人各 40 张
- 4 人房间，不足自动补机器人
- 队友固定对坐；随机庄；换庄不换座
- 创建/加入房间、房间号复制、机器人接管
- 刷新页面自动尝试恢复玩家身份与当前牌局
- 真实选牌、整理·点数、整理·牌序、五十K移尾
- 普通三张 / 三炸模式切换
- 单牌、对子、三张、顺子、连对、炸弹、五十K、大小王炸等规则引擎
- 当前轮次、不要、压牌、出完牌、同队双出完自动结算
- 盘内累计积分、最近30把记录、结算动画
- 发牌、飞牌、炸弹、五十K、结算、粒子、桌面震动和音效
- 手机/桌面自适应与减少动态效果支持
- `/health` 健康检查
- Docker / Render / Procfile 部署配置

## 本地运行

```bash
npm install
npm start
```

打开 `http://localhost:3000`。

## 规则测试

```bash
npm test
```

当前 12 项规则测试全部通过。

## 部署

这是一个需要 WebSocket 的 Node 服务，部署时请使用支持 WebSocket 的 Web Service，而不是纯静态站点。项目已附 `Dockerfile`、`render.yaml` 和 `Procfile`。
